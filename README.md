# EE471 - Week 10: HuggingFace Transformers In-Class Exercise

## Overview
This project demonstrates the use of HuggingFace `transformers` library pipelines for various NLP, Computer Vision, and Audio tasks.

## Task 1 – Transformers Pipeline Tasks
File: `task1_transformers.py`

### Subtasks:
1. **Sentiment Analysis** – Classify sentences as POSITIVE/NEGATIVE
2. **Zero-shot Classification** – Classify text without task-specific training
3. **Text Generation** – Complete an incomplete sentence
4. **Fill-Mask** – Predict missing words in a sentence
5. **Named Entity Recognition (NER)** – Extract person, organization, and location entities
6. **Question Answering** – Validate NER results via Q&A
7. **Text Summarization** – Summarize a paragraph about the 2008 financial crisis
8. **Translation** – Translate English text to Turkish
9. **Image Classification** – Classify images using Google ViT model
10. **Automatic Speech Recognition** – Transcribe audio using OpenAI Whisper

## Setup
```bash
pip install -r requirements.txt
```

## Run
```bash
python task1_transformers.py
```
